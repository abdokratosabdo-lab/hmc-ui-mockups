# HMC UI Mockups — Hajj Medical Center, Naccache

Interactive UI mockup for the Hajj Medical Center website, built as a Claude Design canvas.

**Live preview:** https://abdokratosabdo-lab.github.io/hmc-ui-mockups/

## Contents

- `index.html` — the mockup (copy of `HMC Website.dc.html`, served by GitHub Pages)
- `HMC Website.dc.html` — the original design canvas source
- `support.js` — Claude Design canvas runtime
- `assets/` — logo and image assets

## Running locally

```sh
python3 -m http.server 8000
```

Then open http://localhost:8000
